Configurar no iPhone / iPad＋
  1. Instale o app a-Shell (grátis) na App Store.
  2. Abra o a-Shell, cole os comandos abaixo, um de cada vez (só na primeira vez):
    pip install -U yt-dlp
    Espere terminar e depois cole este:
    curl -L -o ~/Documents/pramim.py https://kcooyakawa.github.io/kco-studio/pramim/pramim.py
  3. No app Atalhos, crie um atalho chamado exatamente pramim com uma única ação do a-Shell: Execute Command. No campo do comando, escreva:
    python ~/Documents/pramim.py
    e, logo depois do texto (com um espaço), toque e insira a variável Entrada do Atalho. Ative "Open a-Shell" para downloads longos.
  4. (Opcional) Nos detalhes do atalho, ative Mostrar na Folha de Compartilhamento e escolha URLs. Assim dá para baixar direto do Instagram/YouTube em Compartilhar › pramim.
  5. Aqui no Safari, toque em Compartilhar › Adicionar à Tela de Início. Pronto: o pra/mim vira um app.
