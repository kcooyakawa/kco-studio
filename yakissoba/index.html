O cardápio do Yakissoba vira um feed.

Protótipo navegável. O cliente encosta o celular no cartão NFC da mesa e desliza pelos pratos como numa rede social.

  1. Simule o toque no cartão
  2. Deslize para cima para o próximo prato
  3. Deslize para os lados (ou use ← →) para trocar de seção
  4. Toque na foto ou em “Ficha” para a ficha técnica
  5. Dois toques na foto para curtir

Pratos e preços vêm do catálogo do restaurante. Bebidas e números do painel são simulados.
